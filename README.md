# 蚁群迷踪（Ant Hunt）

非对称多人社交推理网页游戏 Demo。隐藏者混入 AI 蚁群搬运食物，搜寻者从外观与行为中找出真人并标记淘汰。

## 快速开始

```bash
npm install
npm start
```

| 入口 | 地址 | 说明 |
|------|------|------|
| 玩家 | http://localhost:3000 | 正式联机入口（含单机模式） |
| 调试 | http://localhost:3001 | 单机调试 + 开发者工具面板 |

环境变量（可选）：

- `PORT` — 正式服端口，默认 `3000`
- `DEBUG_PORT` — 调试服端口，默认 `3001`
- `HOST` — 正式服绑定地址，默认 `0.0.0.0`（局域网可访问）；设 `127.0.0.1` 则仅本机
- `DEBUG_HOST` — 调试服绑定地址，默认 `127.0.0.1`（仅本机）

> 修改 `server/` 下逻辑后需**重启服务器**才能生效；`public/` 静态资源刷新浏览器即可。

### 发布到局域网（同网段一起玩）

```bash
npm run start:lan
```

启动后会打印本机局域网地址，例如：

```
蚁群迷踪已启动（局域网模式）
  玩家入口 [以太网 2]: http://192.168.6.236:3000
  调试入口（仅本机）: http://localhost:3001
```

把「玩家入口」那条链接发给同网段的人（同一 WiFi / 同一办公网）即可直接对战，无需公网、无需安装任何东西。要点：

- 浏览器端 WebSocket 地址取自 `location.host`，所以**用 IP 打开页面就会连到该 IP 的服务**，不需要改客户端配置
- **调试服默认只绑本机**：3001 的开发者面板能热改全局调参，不适合暴露给同网段；确实需要时用 `DEBUG_HOST=0.0.0.0 npm run start:lan` 显式开放
- 端口可换：PowerShell 用 `$env:PORT='8080'; $env:DEBUG_PORT='8081'; npm run start:lan`
- 只想自己本机玩：`$env:HOST='127.0.0.1'; npm run start:lan`
- Windows 首次运行若弹出防火墙提示，请勾选允许访问；若已误点取消，用管理员 PowerShell 放行：
  `New-NetFirewallRule -DisplayName "Ant Hunt LAN" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Domain,Private`
- 联机自检（在服务已启动时运行，验证 WebSocket / 建房 / 加入 / 开局 / 快照全链路）：
  `node scripts/smoke-lan.mjs 192.168.6.236 3000`

### 发布到腾讯云轻量应用服务器（公网）

线上入口：**http://111.230.136.201**

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\publish-server.ps1
```

脚本会自动完成打包 → scp 上传 → 远端解包 → `npm install --omit=dev` → 重写 systemd 服务 → 更新 Caddy 站点块并 reload → 本机与公网双重冒烟（含 WebSocket 建房/开局/快照）。重复执行即增量发布，每次都会先把上一版备份到 `/var/www/ants-backups/`。

服务器侧布局：

| 项 | 值 |
|------|------|
| 代码目录 | `/var/www/ants`（属主 `ants:ants`，无登录系统用户） |
| systemd 服务 | `ants.service`（`Restart=always`，开机自启） |
| 正式服 | `127.0.0.1:3210` |
| 调试服 | `127.0.0.1:3211`（**不对外**） |
| 对外反代 | Caddy，`http://111.230.136.201` → `127.0.0.1:3210` |

几个关键决策与坑：

- **为什么入口是裸 IP 而不是域名**：这台机器在腾讯云境内，未备案的域名访问会被劫持到 `https://dnspod.qcloud.com/static/webblock.html`（HTTP 返回 302、HTTPS 直接 reset），连同机已有的 sthgame.top 从部分网络访问也一样；而**裸 IP 的 HTTP 访问完全正常**。客户端 WebSocket 地址取自 `location.host`，所以 IP 入口无需改任何前端代码。
- **调试服不开公网**：3211 的开发者面板能热改全局调参，只监听 `127.0.0.1`。需要时本地开隧道：`ssh -i ~/.ssh/sthgame_deploy -L 3211:127.0.0.1:3211 ubuntu@111.230.136.201`，再打开 `http://localhost:3211`。
- **正式服屏蔽 `/debug.html`**：Caddy 对该路径直接返回 404，避免正式入口暴露调试页。
- **不要用 `caddy validate` 做部署前检查**：它会真的创建日志文件，以 root 跑会留下 root 属主的 `/var/log/caddy/*.log`，之后 caddy 进程写不进去、reload 一直 400。脚本改用 `caddy adapt`（只做配置适配，不碰文件系统）。
- **改 `server/` 后必须重启**：发布脚本已包含重启，手动改线上代码则 `sudo systemctl restart ants`；`public/` 静态资源改完重发即可（浏览器刷新即生效）。
- 排障：`sudo journalctl -u ants -n 50 --no-pager`、`sudo journalctl -u caddy -n 50 --no-pager`、`/var/log/caddy/ants.log`。

## 玩法概览

### 阵营

| 阵营 | 人数 | 目标 |
|------|------|------|
| **搜寻者** | 至少 1 名（最多 9 名） | 标记所有隐藏者直至淘汰，或撑到时间结束 |
| **隐藏者** | 至少 1 名（最多 9 名） | 混在 AI 蚁群中，各自将足够食物运回巢穴完成获胜 |

- 单局时长：默认 **5 分钟**，房主可设 **1～10 分钟**
- 食物目标：每位隐藏者需独立运回 **10 份**（默认），与人数无关；房主可设 **1～30 份**
- AI 蚂蚁：默认 **30 只**，房主可设 **5～100 只**（步长 5）
- 地图：1600 × 1200 px，顶部中央为巢穴，**5 处普通食物堆 + 2 处珍稀食物堆**（可枯竭重生）
- 躲藏点：地图中下部 **3 处**，进入后免疫工具与标记，搜寻者只见影子

### 胜负条件

**隐藏者胜**

- 所有仍在场的隐藏者均完成个人食物配额（获胜）

**搜寻者胜**（满足其一）

- 所有隐藏者生命耗尽被淘汰
- 倒计时归零

### 大厅流程

1. 输入昵称 → 创建或加入房间
2. 选择角色（搜寻者 / 隐藏者）→ 准备
3. 房主可配置对局时长、获胜食物数、AI 蚂蚁数量（变更后全员需重新准备）
4. 房主在「至少 1 搜寻者 + 至少 1 隐藏者、总人数 2～10、全员准备」后开局
5. 结算后可返回大厅重开

## 操作说明

输入方式按设备**自动切换**：触屏设备显示虚拟摇杆 + 技能轮盘，桌面显示鼠标键盘。详见 **[移动端 / 横屏与触屏操作](#移动端--横屏与触屏操作)**。

### 隐藏者

| 操作 | 桌面（鼠标键盘） | 触屏（手机 / 平板） |
|------|------|------|
| 移动 | 按住鼠标左键，朝鼠标方向 | 左下**虚拟摇杆**（8 向，死区 16%） |
| 冲刺 | 按住空格（速度 ×1.5，易暴露） | 右侧「**冲刺**」切换钮（点按开 / 再点关） |
| 突进 | 数字键 **1** 或点击底部工具栏 | 右下轮盘**中心**「突进」按钮 |
| 拾取食物 | 靠近食物堆并**静止 1 秒** | 同左（摇杆松手即静止） |
| 卸货 | 到达巢穴堆放点并**静止 1 秒** | 同左 |

- 搬运普通食物移速 ×0.8，珍稀食物 ×0.5；头上显示食物颗粒
- 自身蚂蚁为绿色高亮；隐藏者方可见队友标识色
- 每位隐藏者 **3 条生命**：被标中减 1 生命并冻结 **10 秒**，有剩余生命则在巢穴复活；归零则淘汰并切换全屏观战
- 视野**面积**固定（等面积缩放），各端分辨率与屏幕形状不同但可见范围一致
- 可看到所有搜寻者的瞄准位置（大手光标）

**突进技能**：朝当前移动方向（静止时朝面向）快速位移 **120 像素**（可在 `server/config.js` 的 `HIDER_TOOLS.dash.distance` 配置），耗时约 0.15 秒；被标中、定身或淘汰时不可用。

### 搜寻者

| 操作 | 桌面（鼠标键盘） | 触屏（手机 / 平板） |
|------|------|------|
| 移动准星 / 平移镜头 | 右键拖拽 | 左下**虚拟摇杆**移动准星 |
| 标记蚂蚁 | 左键点击（约 18px 范围内） | 点按蚂蚁（约 30px 范围内，带涟漪反馈） |
| 使用工具 | 数字键 **1–4** 或点击底部工具栏 | 右下**技能轮盘** 4 扇区 |
| 工具说明 | 鼠标悬停 | **长按 400ms** 弹出说明 |
| 取消瞄准 | ESC 或再按同键 | 轮盘**中心**「取消」按钮 |
| 切换信息素显示 | HUD「信息素」按钮 | 同左 |

**标记规则**

- 标中隐藏者 → 扣 1 生命并冻结（非立即淘汰）
- 标中 AI → 该蚂蚁**逃窜约 1.2 秒**，标记功能进入 **3 秒冷却**（冷却期间不可点击）
- 躲藏点内、巢穴内、已获胜/已淘汰的隐藏者不可标记

工具用法见下方 **[搜寻者工具](#搜寻者工具)** 章节。

## 移动端 / 横屏与触屏操作

### 横屏优先

- 手机 / 平板**请横屏游玩**。竖屏时会显示「请横屏游玩」遮罩（对局不会暂停，转回横屏即恢复操作）。
- 大厅、房间、对局、结算四类界面均按横屏重排：大厅与房间在横向空间充足时自动变为**两列**，矮屏（≤620px 高）压缩留白，全部内容不裁切。
- 刘海 / 挖孔屏通过 `viewport-fit=cover` + `env(safe-area-inset-*)` 避让，摇杆、轮盘、HUD、退出按钮都不会被遮挡。
- 点击「创建房间 / 扮演搜寻者 / 扮演隐藏者 / 开始对局」时会 best-effort 申请**全屏 + 横屏锁定**（iPhone Safari 无元素全屏 API，会自动跳过，不影响开局）。

### 输入方式自动切换

| 设备 | 判定 | 界面表现 |
|------|------|------|
| 手机 / 平板（粗指针） | `pointer: coarse` 或 `maxTouchPoints > 0` | 摇杆 + 冲刺钮 + 技能轮盘 |
| 桌面（精确指针） | 默认 | 鼠标键盘 + 底部工具栏 |

- 运行中会随真实指针类型**热切换**：触屏设备插上鼠标即切回桌面 UI，触摸屏幕立刻切回触屏 UI，无需刷新。
- QA 覆盖办法：URL 加 `?input=touch` 强制触屏，`?input=pointer` 强制桌面；调试服（3001）的 DEV 面板也有「强制触屏操作」开关。强制模式不会改变设备检测本身。

### 触屏控件

| 控件 | 位置 | 说明 |
|------|------|------|
| 虚拟摇杆 | 左下 | MOBA 式浮动原点；死区 16%，松手 120ms 内回中；输出归一化方向向量 |
| 冲刺钮 | 右下上方（仅隐藏者） | 切换式，激活时高亮并显示「加速中」 |
| 技能轮盘 | 右下 | 4 扇区（搜寻者：强光 / 嗅探 / 假食物 / 残影），环形 CD 倒计时 |
| 轮盘中心 | 右下中央 | 搜寻者：标记 / 取消；隐藏者：突进（带环形 CD） |

- 摇杆与轮盘各自独立响应多指操作，不会互相抢触点；控件区域点击不会穿透到画布。
- 切后台、来电、失焦时统一释放输入，隐藏者会补发零向量，避免蚂蚁「失控跑路」。
- 触屏渲染默认走低质量档（跳过 soft-light 合成层），并限制 DPR ≤ 2，兼顾清晰度与帧率。

### 视野说明

隐藏者视野由「固定 4:3 视口」改为**等面积缩放**：可见世界面积恒等于 `HIDER_VIEW_WIDTH × HIDER_VIEW_HEIGHT`（默认 960×720），形状随屏幕变化。这样横屏手机上不会浪费左右大片区域，且手机与桌面同局时判定范围一致。

如需回退到旧的 4:3 letterbox 行为，把 `public/js/const.js` 中的 `HIDER_VIEW_MODE` 改为 `'box'` 即可。

### 真机验收

```bash
npm run start:lan      # 打印局域网地址，手机同网段打开即可
```

建议逐项确认：旋转横竖屏、刘海避让、摇杆手感与死区、轮盘可达性、长按说明气泡、退出对局按钮、断网重连提示。

## 搜寻者工具

搜寻者有三件辅助工具，用于**扰动蚁群、探测真人、设置陷阱**，与左键「直接标记」配合使用。多名搜寻者各自拥有**独立的工具冷却**，互不影响。

### 通用规则

| 项目 | 说明 |
|------|------|
| 激活方式 | 数字键 **1 / 2 / 3**，或点击底部工具栏图标 |
| 施放方式 | 选中工具后**左键点击地图落点**；光束类工具点击即开始，放置类工具点击即生成 |
| 冷却 | 三件工具**各自独立 CD**；开局时全部进入 **5 秒**初始冷却 |
| 瞄准状态 | 选中工具后鼠标变为十字准星；再次按同键或 ESC 可取消 |
| 免疫区域 | 巢穴内、躲藏点内的蚂蚁**不受强光影响**；嗅探与标记在躲藏点内也无效 |

工具分两类：

- **光束类**（强光照射、气息嗅探）：点击后在落点生成效果圈，**跟随鼠标移动**（限速约 280 px/s），持续至时长结束自动停止
- **放置类**（假食物）：点击后在落点**固定生成**实体，无需持续操作

---

### 1 · 强光照射

> 用强光惊扰蚁群，逼 AI 逃窜，从群体反应中找出「不该动却不动」或「动得不对」的个体。

| 属性 | 数值 |
|------|------|
| 快捷键 | `1` |
| 冷却 | 30 秒 |
| 持续时间 | 4 秒 |
| 作用半径 | 120 px |

**效果**

- 在点击位置投射圆形强光，光束会**追随鼠标**在地图上扫射
- 范围内的 **AI 蚂蚁**会高速逃离光源
- **隐藏者不受影响**，不会因强光进入逃窜态——这是重要的推理线索
- 可用来「赶羊」：将蚁群驱赶到开阔地带，便于观察步态、转向与停顿差异

**使用建议**

- 适合在食物堆、回巢路径等蚁群密集处使用
- 强光下仍不逃窜的蚂蚁值得重点观察（可能是隐藏者，也可能只是尚未进入范围）
- 与误标记不同，强光**不会**触发标记冷却

---

### 2 · 气息嗅探

> 释放探测圈扫描区域，嗅探到隐藏者时圈体变红——不直接淘汰，但提供「这片区域有真人」的强提示。

| 属性 | 数值 |
|------|------|
| 快捷键 | `2` |
| 冷却 | 20 秒 |
| 作用半径 | 100 px |
| 未命中持续 | 5 秒 |
| 命中警告 | 1 秒（圈体变红） |

**效果**

- 点击后在落点生成嗅探圈，**跟随鼠标**移动
- 圈内若存在**未冻结、未淘汰**的隐藏者 → 立即触发命中，圈变红并再持续 **1 秒**后结束
- 若全程未嗅探到隐藏者 → 持续 **5 秒**后自动结束
- **巢穴内、躲藏点内**的隐藏者不会被嗅探到

**使用建议**

- 适合在可疑蚂蚁附近或交通要道「扫一遍」，比盲目标记风险更低
- 命中后圈变红是强信号，可立刻配合左键标记或通知队友
- 隐藏者方能看到搜寻者鼠标（大手光标），嗅探扫射时尽量配合强光打乱其走位

---

### 3 · 假食物

> 在地图上放置外观与真食物相同的诱饵堆，专钓「会停下来取食」的真人。

| 属性 | 数值 |
|------|------|
| 快捷键 | `3` |
| 冷却 | 25 秒 |
| 存在时间 | 40 秒 |
| 场上上限 | 8 个 |

**效果**

- 点击地图落点放置假食物堆，外观与真食物**完全一致**
- **AI 蚂蚁不可见**，不会靠近、不会搬运，也不会在其上释放信息素
- **真人隐藏者**若靠近并**静止 1 秒**完成取食交互：
  - 定身 **0.5 秒**
  - 触发 **1.5 秒**高亮警告（对搜寻者可见）
  - **不会得分**，也不会真正拾取食物

**使用建议**

- 适合放在真食物堆附近、回巢必经之路或躲藏点出口
- AI 对假食物完全无反应——若某蚂蚁在假食物旁停下取食，基本可确认为隐藏者
- 可同时布置多个假食物（最多 8 个），形成「筛网」；注意 40 秒后自动消失，需把握时机
- 与强光、嗅探组合：先用工具逼出可疑目标，再在逃路线上预埋假食物

### 工具与标记的配合

| 场景 | 推荐组合 |
|------|----------|
| 蚁群太密，难以点选 | 强光照射 → 观察逃窜差异 → 标记 |
| 有可疑目标但不敢盲标 | 气息嗅探确认 → 立即标记 |
| 怀疑某蚂蚁是真人 | 在其常经过处放置假食物 → 等待取食暴露 |
| 多人协作 | 各搜寻者分工：一人扫射、一人嗅探、一人守标记 CD |

> 标记（左键）与工具相互独立：**误标 AI 只锁标记，不锁工具**；工具 CD 也不影响标记（除非标记自身在冷却中）。

## 伪装与推理

### 外观破绽（5 维度）

每只蚂蚁外观由以下维度决定；隐藏者继承一只 AI 模板，但**随机 1 个维度偏移 1 级**：

| 维度 | 变化 |
|------|------|
| 触角 | 直 / 微内弯 / 微外弯 / 钩状 |
| 腹部条纹 | 无 / 单条 / 双条 / 锯齿 / 斑点 |
| 胸甲色调 | 5 档亮度 |
| 步态摇摆 | 僵硬 / 轻微 / 大幅 / 不规则 |
| 头身比例 | 小 / 正常 / 大 / 方正 |

### 地图要素

- **巢穴**：遮蔽搜寻者视野，巢内蚂蚁对搜寻者不可见
- **普通食物**：1 分/次，枯竭 30s 后重生
- **珍稀食物**：3 分/次，搬运更慢，枯竭 45s 后重生
- **躲藏点**：短暂休整的安全区，搜寻者只见模糊影子

### AI 行为（隐藏者宜模仿）

- **搜寻态**：沿信息素找食物，沿途释放回巢信息素
- **搬运态**：朝巢穴移动，沿途释放寻食信息素
- **逃窜态**：被强光照射或误标记时高速逃离（隐藏者**不会**因强光逃窜）
- **待机态**：低概率原地停顿「梳毛」

信息素可视化：青色 = 指向食物，品红 = 指向巢穴。

### 单机模式

两个端口均支持**无需联机**的单人体验：

- **3000 正式服**：完整玩法，工具 CD 正常
- **3001 调试服**：单机对局默认工具无 CD，附带开发者面板

### 调试模式（端口 3001）

- **开发者工具**：运行时热改 AI 数量/速度、食物参数、工具 CD、标记冷却、光束速度等
- **全局同步**：调试面板写入的调参会热更新 3000/3001 上所有进行中对局
- **默认值持久化**：自定义 DEV 默认值保存至 `server/data/devDefaults.json`
- 调试对局工具无 CD（可通过面板切换）；误标记冷却仍生效

平衡数值集中在 `server/config.js`，包括对局时长、生命数、工具 CD、AI 速度、信息素参数、食物堆与躲藏点配置等。

## 技术栈

- **运行时**：Node.js（ES Module）
- **网络**：原生 `ws` + HTTP 静态文件服务
- **客户端**：原生 Canvas 2D，无前端框架、无构建步骤
- **输入**：Pointer Events 统一触屏与鼠标；键盘沿用 `keydown` / `keyup`
- **架构**：权威服务器模拟，客户端仅负责渲染与输入；多名搜寻者各自独立工具状态与冷却
- **移动端**：横屏优先自适应布局 + 摇杆/轮盘触屏层，按设备能力自动切换；DPR ≤ 2 渲染
