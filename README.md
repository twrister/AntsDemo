# 蚁群迷踪（Ant Hunt）

非对称多人社交推理网页游戏 Demo。隐藏者混入 AI 蚁群搬运食物，搜寻者从外观与行为中找出真人并标记淘汰。

## 快速开始

```bash
npm install
npm start
```

| 入口 | 地址 | 说明 |
|------|------|------|
| 玩家 | http://localhost:3000 | 正式联机入口 |
| 调试 | http://localhost:3001 | 单机调试 + 开发者工具 |

环境变量（可选）：

- `PORT` — 正式服端口，默认 `3000`
- `DEBUG_PORT` — 调试服端口，默认 `3001`

> 修改 `server/` 下逻辑后需**重启服务器**才能生效；`public/` 静态资源刷新浏览器即可。

## 玩法概览

### 阵营

| 阵营 | 人数 | 目标 |
|------|------|------|
| **搜寻者** | 恰好 1 名 | 标记所有隐藏者，或撑到时间结束 |
| **隐藏者** | 至少 1 名 | 混在 AI 蚁群中，将食物运回巢穴直至达成配额 |

- 单局时长：**10 分钟**
- 食物配额：`2 + 隐藏者人数`（例：2 名隐藏者需运回 4 份）
- 地图：1600 × 1200 px，顶部中央为巢穴，5 处可枯竭食物堆

### 胜负条件

**隐藏者胜**

- 累计卸货次数达到食物配额

**搜寻者胜**（满足其一）

- 所有隐藏者被标记淘汰
- 倒计时归零

### 大厅流程

1. 输入昵称 → 创建或加入房间
2. 选择角色（搜寻者 / 隐藏者）→ 准备
3. 房主在「1 搜寻者 + ≥1 隐藏者、全员准备」后开局
4. 结算后可返回大厅重开

## 操作说明

### 隐藏者

| 操作 | 按键 |
|------|------|
| 移动 | 按住鼠标左键，朝鼠标方向 |
| 冲刺 | 按住空格（速度 ×1.5，易暴露） |
| 拾取食物 | 靠近食物堆并**静止 1 秒** |
| 卸货 | 到达巢穴范围并**静止 1 秒** |

搬运时移速 ×0.8，头上显示食物颗粒。自身蚂蚁为绿色高亮。

### 搜寻者

| 操作 | 按键 |
|------|------|
| 平移镜头 | 右键拖拽 |
| 标记蚂蚁 | 左键点击（约 18px 范围内） |
| 切换信息素显示 | HUD「信息素」按钮 |

**标记规则**

- 标中隐藏者 → 淘汰
- 标中 AI → 该蚂蚁**逃窜约 1.2 秒**，标记功能进入 **3–5 秒冷却**（冷却期间鼠标为不可点击样式）

**工具**（各自独立 CD，数字键 1–3）

| 键 | 工具 | CD | 效果 |
|----|------|-----|------|
| 1 | 强光照射 | 30s | 点击地图照射 4s，半径 120px 内 AI 逃离；隐藏者不受影响 |
| 2 | 诱饵食屑 | 25s | 放置 10s，靠近的隐藏者显示「?」 |
| 3 | 群体冻结 | 60s | 全体蚂蚁停止移动 2s，便于观察外观 |

## 伪装与推理

### 外观破绽（5 维度）

每只蚂蚁外观由以下维度决定；隐藏者继承一只 AI 模板，但**随机 1 个维度偏移 1 级**：

| 维度 | 变化 |
|------|------|
| 触角 | 直 / 微内弯 / 微外弯 / 钩状 |
| 腹部条纹 | 无 / 单条 / 双条 / 锯齿 / 斑点 |
| 胸甲色调 | 5 档亮度 |
| 步态摇摆 | 僵硬 / 轻微 / 大幅 / 不规则 |
| 头身比例 | 小 / 正常 / 大 / 方正 |

### AI 行为（隐藏者宜模仿）

- **搜寻态**：沿信息素找食物，沿途释放回巢信息素
- **搬运态**：朝巢穴移动，沿途释放寻食信息素
- **逃窜态**：被强光照射时高速逃离（隐藏者**不会**逃窜）
- **待机态**：低概率原地停顿「梳毛」

信息素可视化：青色 = 指向食物，品红 = 指向巢穴。

## 项目结构

```
AntsDemo/
├── public/              # 客户端静态资源
│   ├── index.html       # 正式入口
│   ├── debug.html       # 调试入口（单机 + DEV 面板）
│   └── js/
│       ├── main.js      # 大厅 / 对局 / 结算流程
│       ├── net.js       # WebSocket 通信
│       ├── renderer.js  # Canvas 渲染
│       ├── seeker.js    # 搜寻者输入与工具
│       └── hider.js     # 隐藏者输入
├── server/              # 权威服务器（10Hz tick）
│   ├── index.js         # 双端口启动
│   ├── createServer.js  # HTTP + WebSocket 实例
│   ├── Room.js          # 房间状态机
│   ├── Game.js          # 核心模拟与胜负判定
│   ├── AntAI.js         # AI 行为与信息素沉积
│   ├── Pheromone.js     # 信息素场
│   ├── traits.js        # 外观破绽系统
│   ├── config.js        # 平衡数值（调参入口）
│   └── protocol.js      # 消息类型常量
└── package.json
```

### 调试模式（端口 3001）

- **单机调试**：无需联机，一键以搜寻者或隐藏者身份开局
- **开发者工具**：运行时热改 AI 数量、速度、食物堆参数等
- 调试对局中工具无 CD、误标记不锁技能

平衡数值集中在 `server/config.js`，包括对局时长、工具 CD、AI 速度、信息素参数、食物堆配置等。

## 技术栈

- **运行时**：Node.js（ES Module）
- **网络**：原生 `ws` + HTTP 静态文件服务
- **客户端**：原生 Canvas 2D，无前端框架
- **架构**：权威服务器模拟，客户端仅负责渲染与输入
